# WorthyopsWebsite

The WorthyOps marketing site: a static, single-page site (HTML, CSS and vanilla JS, no build step).

## Files

- `index.html` – the page
- `style.css` – all styles
- `script.js` – nav, scroll reveals and the results card carousel
- `images/` – client photos
- `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png`, `android-chrome-*.png`, `site.webmanifest` – icons

## Run locally

Serve the folder from its root so the favicon paths resolve, for example:

```bash
npx serve .
```

Then open http://localhost:3000.
